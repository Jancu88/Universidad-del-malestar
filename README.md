# Universidad del malestar

🎨 Guía de Aplicación de la Paleta

• Fondo Principal (#111B1A): Úsalo para el fondo general de la aplicación (body o main-container). Es lo suficientemente oscuro para no cansar la vista, pero tiene un toque de verde que le da personalidad en lugar de ser un negro puro aburrido.
• Superficie / Tarjetas (#1B2826): Aplícalo en los contenedores flotantes, tarjetas (cards), barras de navegación (sidebar/navbar) o modales. Al ser ligeramente más claro que el fondo, genera una excelente ilusión de elevación y profundidad.
• Bordes / Separadores (#2C3E3B): Ideal para las líneas divisorias (<hr>), bordes de tarjetas, o los contornos de los campos de texto (inputs) que no están enfocados. Mantiene la interfaz unida de forma sutil.
• Principal - Brand (#8DD0C8): Tu color estrella (Menta/Turquesa claro). Úsalo para los elementos interactivos clave: botones primarios (con texto oscuro), enlaces, iconos activos, o el borde de un elemento seleccionado.
• Primario Oscuro (#3B7A74): Perfecto para estados secundarios del botón principal (como un efecto hover o pressed), para botones secundarios, o para fondos de etiquetas (badges) donde el texto sea el color menta claro.
• Texto Principal (#E2ECE9): Para títulos, nombres de secciones y el texto principal que el usuario debe leer primero. Su alto contraste sobre el fondo oscuro garantiza una legibilidad perfecta.
• Texto Secundario (#92A8A4): Úsalo para subtítulos, fechas, textos de ayuda o descripciones largas. Al ser más opaco, ayuda a crear una jerarquía visual clara para que el usuario sepa qué es lo más importante.

🚦 Estados del Sistema (Feedback)

Tus colores de estado tienen la saturación ideal para un modo oscuro, ya que no son chillones pero destacan de inmediato:
• Éxito (#66BB6A): Mensajes de "Guardado con éxito", checks de validación o saldos positivos.
• Advertencia (#FFB74D): Alertas de "Acción requerida", procesos pendientes o notificaciones importantes que no bloquean al usuario.
• Error (#E57373): Mensajes de error en formularios, acciones fallidas o alertas críticas de sistema.
• Información (#64B5F6): Consejos (tooltips), guías de usuario o banners informativos.
